# Todo App

A simple and responsive Todo App built with **React** and **Vite**.
This project was created as a practical exercise to learn and strengthen React fundamentals.

## 🚀 Live Demo

[View Live Demo](https://ava-esmaeillli.github.io/react-mini-projects/)

## ✨ Features

* Add new todos
* Edit existing todos
* Delete todos
* Mark todos as completed
* Responsive user interface
* Component-based architecture
* Styled with Tailwind CSS

## 🛠️ Technologies

* React
* Vite
* JavaScript (JSX)
* Tailwind CSS
* HTML5
* CSS3

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ava-esmaeillli/react-mini-projects.git
```

Navigate to the project:

```bash
cd react-mini-projects
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Then open the local URL provided by Vite in your browser.

## 🎯 Purpose

The main goal of this project was to practice React fundamentals through a small real-world project and become more comfortable with:

* Components
* Props
* State
* Event handling
* Conditional rendering
* Rendering lists with `map()`
* Managing form inputs
* Component communication
